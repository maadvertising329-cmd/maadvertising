MA ADVERTISING — STATIC MULTI-PAGE WEBSITE

This version uses plain HTML, CSS and JavaScript. It does NOT require npm, Node.js, React or a build step.

FILES
- index.html    Home
- about.html    About Us
- services.html Services
- blog.html     Blog
- contact.html  Contact Us
- style.css     Shared theme styling
- script.js     Mobile navigation and WhatsApp enquiry form

LOCAL PREVIEW
Double-click index.html to open it in your browser.

GITHUB UPLOAD
Upload all these files to the same root folder of your repository. Keep style.css and script.js next to the HTML files. Do not upload the ZIP itself as a replacement for the individual site files.

CLOUDFLARE
If the current deployment is a Cloudflare Worker, check its existing static asset configuration before replacing files. Do not delete wrangler.jsonc unless you know it is no longer needed.
