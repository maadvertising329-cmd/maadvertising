MA Advertising website image pack
==================================

All files are optimized WebP images. Use the files in /services for the service cards and /applications for the applications cards. The /all-original-project-photos folder contains the supplied project photos converted to WebP with descriptive filenames.

SERVICE CARD MAPPING
- LED Sign Boards -> services/led-sign-boards.webp
- Acrylic LED Signage -> services/acrylic-led-signage.webp
- Glow Sign Boards -> services/glow-sign-boards.webp
- Channel Letters -> services/channel-letters.webp
- Neon LED Signage -> services/neon-led-signage.webp
- Outdoor Branding -> services/outdoor-branding.webp

APPLICATION CARD MAPPING
- Retail storefronts -> applications/retail-storefronts.webp
- Cafés & restaurants -> applications/cafes-restaurants.webp
- Offices & clinics -> applications/offices-clinics.webp
- Healthcare -> applications/healthcare.webp
- Corporate offices -> applications/corporate-offices.webp
- Hotels & hospitality -> applications/hotels-hospitality.webp
- Real estate -> applications/real-estate.webp

Notes:
- These are the best-fit matches from the supplied photos; there was no clearly identifiable hotel/hospitality photo, so a commercial signage photo is used as a general placeholder.
- Keep image proportions and use CSS object-fit: cover for card banners. For the application banners, a wide 16:9 crop may look best.
- Original website screenshots were excluded from the asset pack.
